یک هاست cpanel تهیه کرده و محتویات پوشه file را به هاست خود منتقل کنید . در phpmyadmin یک دیتابیس ساخته و دسترسی های لازم بین دیتابیس و کابر را برقرار نموده و سپس فایل database.sql را در دیتابیس ساخته شده ایمپورت کنید

سپس فایل config.php را باز نموده و اطلاعات دیتابیس خود را وارد نمائید :

define('DB_NAME', 'database_name');

define('DB_USER', 'database_user'); // معمولاً نام کاربری با نام دیتابیس یکی است

define('DB_PASS', 'database_password'); // رمز واقعی دیتابیس را وارد کنید
